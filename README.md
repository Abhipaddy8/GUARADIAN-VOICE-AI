# GuardianVoice AI: Familial Digital Twin

**Autonomous Dementia Care Orchestration on Vultr**

GuardianVoice AI is a cyber-physical platform that uses real-time smartwatch vitals to drive a "Familial Digital Twin." The system autonomously intervenes during dementia-related agitation using cloned family voices, de-escalating crises via personalized memory anchors.

## The Stack
- **Infrastructure:** Vultr High-Performance VM (Central System of Record)
- **Brain:** Google Gemini 2.0 Flash (Autonomous Reasoning)
- **Simulation:** Webots (Headless Digital Twin streamed via Vultr)
- **Voice:** Retell AI (Telephony) + ElevenLabs (Cloned Familial Voice)
- **Sensors:** Samsung Fit3 (Hardware-in-the-loop telemetry)

## Features
- **Bio-Robotic Trigger:** Real-world heart rate spikes trigger virtual robot navigation
- **Multimodal Perception:** Gemini analyzes simulation states to plan de-escalation
- **Memory Anchors:** Vultr-hosted database stores patient history to ground AI agents
